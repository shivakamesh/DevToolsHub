# It's All Dev Tools

🌐 **Live site: [https://www.itsalldevtools.com](https://www.itsalldevtools.com)**

50+ free developer tools and electrical engineering calculators that run **100% in your browser**. Nothing you type is uploaded, there's no sign-up, and the tools work offline once a page has loaded.

Built with **Blazor WebAssembly (.NET 8)** and prerendered to static HTML for fast loads and SEO.
